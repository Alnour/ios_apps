# ios_apps

One folder per iOS app, plus shared tooling and docs:

- `tools/` — reusable scripts. `new-ios-app.sh <Name> [bundlePrefix]` scaffolds an app from
  `tools/template/`; `build.sh`, `run.sh`, `test.sh`, `screenshot.sh` take `[Name] [sim]`
  (default sim "iPhone 17 Pro"). Each app's `Makefile` forwards to them (`make run`).
- Every app's Xcode project is **generated by xcodegen** from its `project.yml`. Edit the yml
  (targets, Info.plist `info.properties`, settings) and the scripts regenerate; never hand-edit
  `.xcodeproj`, and it is git-ignored.
- `docs/` — local Context Hub source `apple` with Apple framework docs (built by
  `tools/fetch-apple-docs.sh`). Before writing code against a framework:
  `chub search apple` → `chub get apple/<id> --lang swift`. Add learnings with
  `chub annotate apple/<id> "note"`. Refresh the corpus by re-running the fetch script.
- Toolchain here: Xcode 26.x, iOS 26 SDK, Swift 6, SwiftUI, SwiftData. Simulators have no Mail
  account, no Messages, no WhatsApp — exercise URL fallbacks there and compose sheets on device.
