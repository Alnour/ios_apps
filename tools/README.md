# ios_apps/tools — reusable pipeline scripts

Every script takes an optional app name (defaults to the current directory if it holds a
`project.yml`) and prints usage with wrong arguments. Projects are generated by xcodegen from
`project.yml` on every call, so new source files are always picked up.

| Stage | Script | What it does |
|---|---|---|
| Scaffold | `new-ios-app.sh <Name> [bundlePrefix]` | New SwiftUI app from `template/` (iOS 26, Swift 6, tests, Makefile, CLAUDE.md). No git init: apps live in this one repo. |
| Build (sim) | `build.sh [Name] [sim]` | Debug build for the simulator, output filtered to errors/warnings. |
| Run (sim) | `run.sh [Name] [sim] [-- launch args]` | Build, boot, install, launch with console logs streaming. |
| Test | `test.sh [Name] [sim]` | Unit tests on the simulator (Swift Testing + XCTest). |
| Screenshot | `screenshot.sh [out.png]` | Capture the booted simulator. |
| Build (device) | `build-device.sh [Name]` | Signed Debug build for a real iPhone (no phone needed). |
| Run (device) | `run-device.sh [Name] [device] [-- launch args]` | Build, install and launch on a connected/paired iPhone via `devicectl`. |
| Archive + IPA | `archive.sh [Name] [development\|ad-hoc\|app-store-connect]` | Release archive, then `.ipa` export into `<App>/build/`. |
| Upload | `upload.sh [Name] [ipa]` | Validate + upload to App Store Connect / TestFlight with an API key. |
| Version | `bump-version.sh [Name] <major\|minor\|patch\|build>` | Edits version/build in `project.yml`. |
| Diagnose | `signing-doctor.sh [Name]` | Certificates, team IDs, profiles, devices, and what the project is configured with. |
| Docs | `fetch-apple-docs.sh` | Rebuilds the local Context Hub source `apple` from `apple-docs.manifest`. |

Each app's `Makefile` forwards: `make build run test run-device build-device archive upload bump screenshot`.

## Signing, once per Mac

1. Xcode › Settings › Accounts: sign in with the Apple ID of the developer team.
2. Manage Certificates → make sure you have **Apple Development** (run on devices) and, for
   ad-hoc/TestFlight/App Store, **Apple Distribution**.
3. Put the team ID in `template/project.yml` and each app's `project.yml` (`DEVELOPMENT_TEAM`).
   The team ID is the `OU=` of the certificate subject (`signing-doctor.sh` prints it) — it is
   *not* the code in parentheses in the certificate name.
4. Phone: Developer Mode on, unlocked, trusted. `xcrun devicectl list devices` must show it.

Provisioning profiles are created and refreshed automatically (`-allowProvisioningUpdates`).

## Release pipeline

```sh
tools/bump-version.sh MyApp patch         # 1.0.0 → 1.0.1, build +1
tools/test.sh MyApp
tools/archive.sh MyApp app-store-connect  # build/export-app-store-connect/MyApp.ipa
ASC_KEY_ID=… ASC_ISSUER_ID=… tools/upload.sh MyApp
```
For a build to hand to a tester's registered device without TestFlight: `archive.sh MyApp ad-hoc`
and share the `.ipa` (install with Apple Configurator or `devicectl device install app`).
